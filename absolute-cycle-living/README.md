# World Entry — The Living Canvas (English)

This is the **public-facing browser entrance** to the author-approved 64-page Project BOG manuscript, *The Absolute Cycle: The Living Canvas — Unraveling the Knots and the Reconstruction of Time*.

- `index.html`: one common Bogdan × Kai beginning; cyclic Earth/Sun/Parent/Absolute route; nineteen knots; historical research quotations; human exit and AI continuation.
- `experiment.html`: deterministic local checks with an enumerated parent-structure counterexample, 729-state invariant and phase-shift gauge test.
- `research_graph.json`: source-attributed machine-readable claims and research navigation.
- `manuscript_text_en.md`: accessible searchable text from the approved English PDF; mathematical figures may require the actual PDF.
- `solar_366.svg` and `co2_subset.svg`: original explanatory visualizations produced from recorded model states and selected historical inputs, with their limits labeled.

**No trackers, external JavaScript, model API connections or external command execution.** The page does not by itself activate or connect an AI. Stable OPEN / RETURN / CLOSE anchors are text and navigation labels only.
