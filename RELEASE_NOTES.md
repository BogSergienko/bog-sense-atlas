# First public release · 2026-11-01

**Scope:** v0.2.0, static single-page browser application, RU/EN, six built-in themed routes, seven meaning stages plus return, user-generated routes and JSON portability, Markdown journey export, locally generated AI conversation prompts, optional links to published research.

**Quality boundary:** Chromium-based local automated test report exists for private v0.2 (navigation, route return, authoring, export/import, HTML-injection escaping, mobile rendering). The public release preserves the application script and only adds nonfunctional HTML metadata. This does not prove correctness on every browser or device. A live GitHub Pages check and owner acceptance remain required.

**Excluded:** no private source archive, memory, proprietary models, API keys, analytics, payments, account system, model inference, or remote sync.
