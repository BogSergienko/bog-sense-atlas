Первый открытый расчёт

Два цикла + совместное наблюдение + обратимая память. Простой публичный эксперимент, не закрытый движок R5.

Холст: переплетение двух циклов

Цикл A0
Цикл B0
Связь c0
Память h0
Шаг 0. Оба цикла готовы к совместному обновлению.

Почему это вычисление корректно

Публичная математическая модель
a′ = (a + 1) mod 2
b′ = (b + 1) mod q
c′ = a′ XOR (b′ mod 2)
h′ = h XOR c′
a = (a′ − 1) mod 2
b = (b′ − 1) mod q
h = h′ XOR c′

Оба цикла сдвигаются за один шаг. Их совместная наблюдаемая величина c зависит от двух фаз. Внутренний бит h обратимо запоминает результат — при обратном ходе стирание записи является частью точного возвращения.

Последовательность: 0 0 0 1 1 1

Для 2×3 после 6 шагов циклы возвращаются к началу, но память h=1; после 12 шагов возвращается и память. Проверяемый пример — не доказательство новой физики.
