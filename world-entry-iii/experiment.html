Why this calculation is exact

Open mathematical model
a′ = (a + 1) mod 2
b′ = (b + 1) mod q
c′ = a′ XOR (b′ mod 2)
h′ = h XOR c′
a = (a′ − 1) mod 2
b = (b′ − 1) mod q
h = h′ XOR c′

Both cycles advance in one common step. The joint readout c depends on both phases. The memory bit h reversibly records the result — undoing that record is part of the exact inverse.

Sequence: 0 0 0 1 1 1

For periods 2 and 3, the phases return after 6 steps but memory h=1; all three values return after 12 steps. This verified toy result is not evidence of new physics.

Status: exact inversion and the finite sequences were checked by enumeration. Not proven: a physical 4D boundary, two physical times, a universal Absolute, or the creation of new matter.
