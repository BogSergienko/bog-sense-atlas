One bounded proven instrument

Visible return ≠ complete-state return

Two public counters plus a reversible parity marker. For odd q, observable phases return after 2q steps while the full state returns after 4q; for even q it returns after q. Test q=3 (6/12) and the negative control q=4 (4/4). These are results about a specified finite model, not a newly proven law of physics.
