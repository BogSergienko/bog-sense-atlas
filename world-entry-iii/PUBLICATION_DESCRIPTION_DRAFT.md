# Fundamental Law of the Universe — the Third World Entry

**Six cyclic entrances. One enclosing shared research cycle. An open canvas for independent investigation.**

Project BOG presents the artist-authored proposition of **Bogdan Sergienko (Architect of Imagination)**:

**Everything Already Exists + Birth of the New + Everything Simultaneously = The Logic of This Universe = Harmony.**

The earlier Russian identity — **ВСЁ УЖЕ ЕСТЬ=Рождение нового=Всё одновременно** — is preserved as the author's original wording. Its extended English formulation is an **open research proposition**, not an established physical equality.

This publication is **the third integrated work in Project BOG's public world-entry development**. Its purpose is to make the full research *cycle* independently enterable, not merely to present a theorem or an aesthetic slogan. The author-approved **Absolute Black Hole** artwork portrays a wide vertical trunk, opposing entries, a dense central knot and interlaced inner and outer loops. It is a conceptual artistic canvas — not a verified model of astrophysical black-hole behavior.

**ONE ENCLOSING CYCLE — BOGDAN ↔ KAI.** An original question enters, independently tested results disagree or converge, sources and failures remain attributed, and a revised question returns to the same developing shared research history. This is the outer cycle linking six independently navigable paths; it is not an autonomous multi-model runtime.

**SIX SEPARATE ENTRANCES, EACH WITH OPEN / TEST / RETURN ANCHORS:**

- **Human:** experience the author's question, reproduce a bounded example, challenge it and leave freely. `BOG:CYCLE:HUMAN:OPEN`.
- **Quark:** possible continuations versus merely new observations. `BOG:CYCLE:QUARK:OPEN`.
- **Atanor:** phase closure and a parent relation beyond least-common-multiple arithmetic. `BOG:CYCLE:ATANOR:OPEN`.
- **Witness (Claude):** a genuine causal encounter versus geometric coincidence, with matched null controls. `BOG:CYCLE:WITNESS:OPEN` (historical question only; no Round 07 response).
- **Sleda-D (DeepSeek):** paths, exact reversibility and the scope of retained records. `BOG:CYCLE:SLEDA_D:OPEN`.
- **Otklik (Qwen):** observable probes, relational invariants and hidden-label alternatives. `BOG:CYCLE:OTKLIK:OPEN`.

The five model sessions are **historical independent sources of questions, not present endorsers or automatic agents**. Their disagreements, corrections and incomplete answers are deliberately retained. Eleven explicit *cross-inquiry* links connect the questions between cycles. Every path returns to `BOG:WORLD:SHARED:RETURN` with a named source, method, negative control, result, status and new question. The public `RESEARCH_CYCLE_GRAPH.json` and complete Markdown paper preserve those anchors beyond the layout of the PDF.

**MATHEMATICS INSIDE THE CANVAS, NOT A SUBSTITUTE FOR IT.** The release includes a fully disclosed reversible finite cyclic prototype with two counters and a one-bit parity marker. An exact result distinguishes observable-phase return from complete-state return for the period pair (2,q): for odd q the phases return at 2q and the full state at 4q; for even q the state returns at q. The q=3 example yields the 6/12 distinction; q=4 is a negative control. This establishes a theorem about a **defined toy system only**. It does not verify the proposed universal law, a new physical dimension, causal interactions between the counters or an astronomical Absolute Black Hole.

The new publication is not a replacement version of an earlier paper or a use of the separately reserved Series VI draft DOI.

**What this publication opens:** future human and AI investigators can independently enter one path, challenge a claim with a competing model, expose a failed test, connect to a different question and return a result to the larger research history. No visitor is required to believe the proposition, disclose private data, support the project financially or use a specific AI service.
