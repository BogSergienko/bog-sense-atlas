# Project BOG · Sense Atlas v0.2 — first public release

**Live experience:** activate GitHub Pages for this repository (Settings → Pages → Deploy from a branch, `main` and `/(root)`). The entry point is `index.html`.

Sense Atlas is a free, interactive **question-path builder**. Each route asks questions, lets you accept or challenge premises, and returns to an opening question with the history of your answers intact. It does **not** claim to measure intelligence, philosophical truth, religious certainty, or cognitive improvement.

## Available paths / Направления

- Question Zero / Вопрос Ноль — original foundation of the cycle
- Philosophy / Философия — claims, reasons and revisions
- Religion / Религия — interpretations and differences
- Research / Исследования — hypotheses and limits
- Work / Работа — questions and practical choices
- AI Dialogue / Диалог с ИИ — generate a draft conversation prompt

**Make your own:** copy a route, edit its eight questions, and export or import the route as JSON. Your answers can be downloaded as Markdown. The AI conversation prompt is copied manually; it does not contact an AI service.

**Privacy:** No account, analytics, API calls, tracking or cloud storage is built into this release. Answers and custom routes are stored in the browser's local storage when permitted. External links open only on click. See `PRIVACY.md`.

## CYCLE CLOCKS — Reversible Event Time (3 November 2026)

**[OPEN THE INTERACTIVE CYCLE CLOCKS](cycle-clocks/index.html)** · [Source, model and limits](cycle-clocks/README.md) · [Wikiversity addendum](cycle-clocks/WIKIVERSITY_APPEND_20261103.wiki) · [Enclosing research preprint](https://doi.org/10.5281/zenodo.23903785)

This is Project BOG's public reversible two-cycle event clock: a comparison with civil time, TICK / A and TOCK / B, independently ordered and joint events, visible/full-state recurrence (6/12 at q=3), exact reversal of labelled transitions, and an even-q negative control. It is a mathematical prototype and research invitation, not a validated physical time standard.
