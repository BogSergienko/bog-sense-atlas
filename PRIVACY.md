# Privacy / Приватность — Sense Atlas v0.2

**English.** This version does not ask for registration, send your answers to a server, track usage, or use analytics. Built-in links to Zenodo and Religious Forums only open when selected, at which point those websites apply their own policies. Personal answers, drafts, and imported routes remain in your browser’s local storage when it is available; removing browser data may remove them. Use JSON export to back up custom routes and Markdown export to save completed paths. Do not include secrets or sensitive personal information in a prompt you paste into another AI service. Any exported file is your responsibility to share or keep private. This public repository includes no private Project BOG memory or unpublished research.

**Русский.** Эта версия не требует регистрации, не отправляет ответы на сервер и не использует аналитику. Ссылки на Zenodo и Religious Forums открываются только по нажатию; там действуют правила соответствующих сайтов. Ответы и собственные маршруты хранятся локально в браузере, если хранилище доступно. При очистке данных браузера они могут исчезнуть. Для резервной копии используй экспорт JSON и Markdown. Не вставляй пароли и чувствительные сведения в промпт, который отправляешь другому ИИ. В публичном репозитории нет приватной памяти Project BOG или неопубликованных исследований.
