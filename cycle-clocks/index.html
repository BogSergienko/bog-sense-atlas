The exact rules behind CYCLE CLOCKS

X = (a, b, h) a ∈ Z₂, b ∈ Zq, h ∈ Z₂ c(a,b) = a XOR (b mod 2) A: a'=(a+1) mod 2; h'=h XOR c(a',b) B: b'=(b+1) mod q; h'=h XOR c(a,b') J: a'=(a+1) mod 2; b'=(b+1) mod q; h'=h XOR c(a',b') For joint J and odd q: visible return after 2q joint events full-state return after 4q joint events For joint J and even q: full-state return after q joint events.

A, B, and J are individually invertible when the event type is known. Automatic playback uses the device timer solely to schedule the visual demonstration, not to define the unit of cyclic time. This is a finite event-clock prototype, not a new physical unit or replacement for atomic clocks.

PROJECT BOG · RESEARCH PRINCIPLES AND PROVEN RESULTS

What drives these clocks?

01 · AUTHORIAL PROPOSITION

Existing possibility and emerging relation

Everything Already Exists + Birth of the New + Everything Simultaneously = The Logic of This Universe = Harmony. This is Bogdan Sergienko's research hypothesis, not an established algebraic or physical law. The clocks explore one small mathematical question it raises.

02 · TWO ENTRANCES

Independent cyclic processes

Events A and B have separate phases and need not share a physical clock. The interface allows A, B, and a deliberately joint event J. Independent paths can yield different full traces despite identical visible phases.

03 · RELATION AND OBSERVATION

Visible return ≠ full return

Projection π(a,b,h)=(a,b) hides h. The visible projection can recur while the full state differs. At q=3, joint phases return at event 6 and the full state at event 12.

04 · REVERSIBILITY

Every specified update has an inverse

A, B, and J are reversible on the defined finite state space when the event label is known. Undo restores the previous snapshot; this does not imply all natural processes are reversible.

05 · ORDER AND NEGATIVE CONTROL

A→B is not always B→A

The parity marker can distinguish order of events at odd-q boundaries. At q=4 this particular difference disappears. A negative control matters as much as a positive example.
