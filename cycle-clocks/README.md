## Research principles, not established physical laws

1. **Authorial identity (open hypothesis).** Everything Already Exists + Birth of the New + Everything Simultaneously = The Logic of This Universe = Harmony. The use of +/= is conceptual, not an already defined physical equation.
2. **Two cyclic entrances.** A and B may advance independently or through one joint event J. Counting events does not require assigning them units of Earth seconds.
3. **Projection versus full-state recurrence.** X=(a,b,h) and π(X)=(a,b). Same visible phases need not imply same complete state.
4. **Reversible update.** For the defined model, labelled A, B, J events have exact inverses; to invert a history one must know the event labels.
5. **Order and negative controls.** A→B and B→A can reach matching visible phases with different h for odd q boundary starts; q=4 is the negative control.
6. **Open research return.** A claim becomes useful when accompanied by a reproducible test, a counterexample criterion and a route back to its origin.

## Exact finite model

Let a∈Z₂, b∈Zq, h∈Z₂. Define c(a,b)=a XOR (b mod 2). On any event move its indicated counter(s) and update h←h XOR c(new a,new b). For the joint map J, if q is odd the visible phase period is 2q and the full-state period is 4q. For even q, the full-state period is q. The q=3 example returns its visible phases at event 6 and its full state at event 12. This is a finite model theorem, not a physical time law.
