# BOG Cycle Engine — The Observable Machine 0.1.0

Open `index.html` to explore three public finite-model experiments. This is a self-contained, dependency-free mathematical laboratory built from formulas in public Project BOG research. It makes no physical-device or speedup claim. All claims are reproducible without payment.

For sources and precise limits, read `research-note.html`. To verify a downloaded JSON receipt run `python verify.py receipt.json`; to execute the included witness tests run `python verify.py` (Python 3.9+, no external modules).

For the full JS/Python acceptance suite, use the free reproducibility ZIP's `tests/acceptance.py` and `tests/test_model.cjs` (Python 3.9+, Node 18+). Run with assertions enabled.
