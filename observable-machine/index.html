A

CYCLE RETURN / ONE PERIOD, MANY STRUCTURES

A return is not a blueprint.

These clocks all advance once per event. Compare their first common return, then look inside the period.

Comma-separated integers, 2–64; at most six per system.

T = lcm(p₁, …, pₙ)

At each integer t, a mark means one component has returned. The common period says when all return together; it does not specify how many components there are.

Read the argument and source ↗

Plot shows events 0–48. Periods are calculated exactly; long periods need not fit in the plot.

The contradiction to test

“Equal common return implies equal internal structure” is false: {6,8,12} and {3,8} both return at 24. The control {5,8} returns at 40. Even observing every component period would not identify unmeasured connections between components.

HIDDEN HISTORY / CHOOSE YOUR OBSERVATION

Two journeys. One surface.

A moves the first counter. B moves the second. After either event, a parity bit h records a joint readout.

Start from X = (0, q−1, 0). Compare A → B with B → A.

c(a,b) = a XOR (b mod 2)

h′ = h XOR c(a′,b′)

Only the indicated counter moves. Try odd and even q. A different event order need not leave a distinguishable final state.

Could another phase observation help?

Starting from the same phases, all future A/B/J phase observations agree, because the counters never depend on h. Direct observation of h separates the odd-q example.
